# User testing of the database entry designs

The example instrument is the EU Machinery Regulation 2023/1230. Open the clone at https://cjimmylin.github.io/embodied-ai-governance/docs/pages/clone/index.html#record and use the tab row.

## The three questions (same for every user)

1. Whom does this regulation bind?
2. Is it in force, and since when?
3. What does it require on physical safety?

Order of tabs for each user: Current first, then two of Dossier, Passport, Scorecard, Questions and Lifecycle (rotate so each design gets two users), then Recommended.
