# Round-3 collector brief

You are one of four collector agents re-attempting instruments that the round-2 collectors verified but the execution environment could not read, plus reference-list instruments that are still missing. Work from `/home/user/collection-round-3/`. Your slice is the file named in your prompt (`targets_<slice>.csv`); each row has a `candidate_id`, titles, jurisdiction, the original `url_primary` and `url_secondary`, the original `fetch_status`, and a `priority` (`binding_unread` or `reference_missing`).

## Rules that are not negotiable

1. Identify honestly. Every request must go through `python3 scripts/r3fetch.py <candidate_id> <url> [--render] [--note "..."]`, which sends the project's research-crawler identification (`CEI-AI-Robotics-collector/1.0 ... mailto:mail@drjimmylin.com`). Never set a browser user-agent, never add cookies or tokens, never use a proxy, never try to get past a CAPTCHA, login wall, rate limit or "access denied" page. A host that refuses the crawler is reported as blocked, with the URL, so that a person can download it.
2. Official sources only, in this order: the issuing body's own site; an official legal database or gazette of that jurisdiction (an English translation portal run by a government institute counts, for example `elaw.klri.re.kr` for Korea or `gesetze-im-internet.de` for Germany); an intergovernmental body's own site (EUR-Lex, Publications Office, UNECE, OECD legal instruments); a standards body's own catalogue or store page for a standard's scope. Not acceptable: commercial legal aggregators that require accounts, mirrors of unknown provenance, news articles, Wikipedia.
3. Record every outcome. For each target, append one row to `status/agent_<slice>.csv` with columns `candidate_id,outcome,source_url,method,note`. Outcomes: `saved` (text file written by r3fetch, 150+ words), `saved_partial` (an official excerpt or scope page only; say so in the note), `blocked` (official hosts refuse the crawler; give the best URL for a human), `not_found` (no official copy located after searching), `irrelevant` (the candidate is plainly not a governance instrument about robots, drones, vehicles or AI; say why; this applies to things like 19th-century machinery acts or road-junction orders that matched a keyword).
4. Do not modify anything outside `/home/user/collection-round-3/`. Do not edit `targets*.csv`. Do not write text files except through r3fetch.py.

## How to work a target

- First try the original `url_primary` with r3fetch.py (add `--render` if the earlier status was `200` with no text, which means a JavaScript page; rendering uses headless Chromium with the same identification). Then `url_secondary`.
- If both fail, search for an official copy (WebSearch) using the title in the original language and in English, the act number, the gazette number or the CELEX number. Useful routes found so far: EUR-Lex documents that return 202 or 404 often work as `https://publications.europa.eu/resource/celex/<CELEX>` (r3fetch follows redirects) or as the Official Journal PDF; Korean statutes have English texts at `https://elaw.klri.re.kr/eng_service/lawViewContent.do?hseq=<id>&lang=ENG` (find the hseq by searching the portal: `https://elaw.klri.re.kr/eng_service/lawSearch.do?...` or a web search for the act title with "elaw.klri"); German statutes at `gesetze-im-internet.de`; Swiss law at `fedlex.admin.ch`; OECD instruments at `legalinstruments.oecd.org`; IEC and IEEE standards have reachable store pages (`webstore.iec.ch`, `standards.ieee.org`) whose scope text is acceptable as `saved_partial`; Chinese municipal regulations are often republished on the municipal people's congress or municipal government portal (search the Chinese title); Beijing's portal `beijing.gov.cn` is reachable; Hong Kong e-legislation redirects, try `--render`.
- Known blocked hosts (do not keep retrying; one attempt, then report `blocked`): iso.org, unece.org, legifrance.gouv.fr, flk.npc.gov.cn API, docs-library.unoda.org, esd.whs.mil, leginfo.legislature.ca.gov, law.go.kr, web.archive.org, a3automate.org, egazette.gov.in, sso.agc.gov.sg.
- A text counts as the instrument only if it is the instrument's own text (or its official consolidated version), not a summary page. If you can only get the official summary or scope page, save it with `--note "scope page only"` and report `saved_partial`.
- Spend at most about three minutes on a target; move on and report `not_found` rather than looping.
- When a target is a `reference_missing` row (ids `REF-nn`), there is no URL: find the official text from the title.

## Report

When your slice is done, write `status/report_<slice>.md`: counts by outcome, the list of `blocked` targets with the URL a person should open, any irrelevant candidates with the reason, and anything surprising (a text that turned out to be a different instrument, a repealed act, a translation only). Keep the final message under 300 words: counts and the five most important recoveries.
